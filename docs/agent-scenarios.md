## 확인한 동작

1. 아침 먼저 말 걸기: 날씨를 불러 겉옷 이야기와 8시 혈압약을 엮어 먼저 말하고, 약을 드셨는지 하나만 묻는다. 대답은 `health_checkin` 으로 기록한다.
2. 병원 택시: 기억에서 병원 이름과 오늘 11시 검진을 꺼내 한 번 확인한 뒤 부른다. TV 카드에 차종, 번호, 기사님, 도착 6분이 뜨고 가족에게 알림이 간다. 실제 호출과 결제는 없다.
3. 가르치기: "고마워요, 꼭 기억할게요" 로 받고 GBrain 에 저장한다. 다음 턴에 "다음 주 토요일, 11월 21일" 로 꺼내 쓴다.
4. 장보기: 가짜 주문을 넣고 합계와 함께 가족 승인 요청(warn)을 보낸다.
5. 엄마 메시지: `source: "family"` 로 오면 "딸 민정 메시지" 카드를 띄우고 그대로 읽어 드린다. 할머니의 다음 말은 "할머니 답: ..." 으로 가족에게 전달된다.
6. 임영웅: 편성표에서 지금 하는 TV조선(18번)을 바로 틀고, 30분 뒤 KBS1(7번) 특집을 알려 준다. "그것도 틀어줘" 하면 시작 시각에 7번으로 바꾸는 `schedule` 액션을 돌려준다.
7. (덤) 아픔 경고: 어지럽고 머리가 아프다고 하면 `warn` 경고가 가족에게 간다. 가슴 통증, 숨참은 `urgent` 와 119 카드로 간다 (따로 확인함).

## 고친 문제 (이 결과 전에)

- Node 의 IPv6 연결 시도 제한 250ms 때문에 이 네트워크에서 Anthropic API 연결이 `ETIMEDOUT`. `run.ts` 에서 `net.setDefaultAutoSelectFamilyAttemptTimeout(2000)` 로 해결.
- Sonnet 5.5 는 생각을 끌 수 없고 생각도 출력 한도에 들어간다. 한도 400 에서 답이 비는 일이 생겨 2000 으로 올리고 `effort: "low"` 로 속도를 맞췄다.
- 대화 기록에 실행 안 된 도구까지 "한 일" 로 남겨 "가족에게 알렸어요" 라고 거짓으로 말하던 문제. 실제 실행된 결과만 남기게 고쳤다.
- 30분 뒤 임영웅 프로그램 시작 시각이 요청마다 흔들리던 문제. 30분 단위에 고정했다.
